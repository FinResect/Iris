## 2. 系统框架与典型应用

> 来源：**【PDF2】** 1.1 / 1.2。

SC431HAI 是数字 CMOS 图像传感器，最高支持 2560×1440 @ 60fps，输出 raw 图像，有效像素窗口 2568×1448，支持窗口化、水平镜像、垂直倒置等片上操作，寄存器通过标准 I2C 读写，并可通过 **EFSYNC/FSYNC** 引脚实现外部控制曝光。

**信号接口（典型应用）**：

| 信号 | 方向 | 说明 |
|---|---|---|
| SCL / SDA | 输入 / 双向 | I2C 从机接口，需 4.7kΩ 上拉到 DOVDD |
| XSHUTDN | 输入 | 复位，内置上拉，低有效 |
| EFSYNC | 输入 | 外部帧同步 |
| FSYNC | 输入/输出 | 输入为外部帧同步；输出为 LED Strobe |
| EXTCLK | 输入 | 外部时钟 |
| MIPI_CLK / DATA0~3 | 输出 | MIPI 差分时钟与数据 |
| AVDD / DVDD / DOVDD | 电源 | 2.8V / 1.2V / 1.8V |
| AGND / DOGND | 地 | 模拟地 / IO 地 |

## 3. 电源域与上/下电时序

> 来源：**【PDF2】** 1.3。

### 3.1 电源域

| 电源 | 典型电压 | 说明 |
|---|---|---|
| AVDD | 2.8V | 模拟电源 |
| DVDD | 1.2V | 数字电源 |
| DOVDD | 1.8V | I/O 电源（决定 I2C/IO 电平） |

### 3.2 上电时序

上电顺序（图 1-3）：

```
DOVDD ──┐ T1
DVDD  ───┴──┐ T2
AVDD  ──────┴──┐ T3
XSHUTDN ────────┴──┐ T4
EXTCLK  Available before power on.
```

- **T1 ≥ 0ms，T2 ≥ 0ms，T3 ≥ 0ms，T4 ≥ 4ms。**
- MIPI CK/Data lane 依次经 `Hi-Z → LP11 → LP01 → LP00`。

### 3.3 下电时序

- **T0 ≥ 6 EXTCLK，T1~T4 ≥ 0ms**（图 1-4）。
- 在 **DOVDD 下电状态下，禁止 XSHUTDN / EXTCLK / SDA / SCL 为高电平**。
- CK/Data lane 依次 `LP11 → Hi-Z`。

### 3.4 睡眠模式

停止输出图像数据流，保持当前寄存器值，支持 I2C 读写：

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| 软睡眠使能 | `0x0100` | `0x00` | Bit[0]：1 = 退出睡眠；0 = 进入睡眠 |
| 低功耗软睡眠 | `0x0100` + `0x302c` | `0x00` | stream off：`0x302c=0x0f` → `0x0100=0x00`；stream on：`0x302c=0x00` → `0x0100=0x01`（**顺序不可变更**） |

### 3.5 复位模式

- 拉低 `XSHUTDN`（此时不支持 I2C 读写）；
- 或写 `0x0103[0] = 1`（软复位，持续 150ns）。

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| 软复位使能 | `0x0103` | `0x0` | Bit[0]：soft reset |

## 4. I2C 配置接口

> 来源：**【PDF2】** 1.4。

- 消息格式：**16-bit 地址 + 8-bit 数据 + 7-bit 设备地址**。
- 设备地址由 PAD **SID** 电平决定（SID 内置下拉，默认低）：

| SID | 7-bit I2C 地址 | 8-bit 写地址 | 8-bit 读地址 |
|---|---|---|---|
| 低电平（默认） | `7'h30` | `8'h60` | `8'h61` |
| 高电平 | `7'h32` | `8'h64` | `8'h65` |

> **【工程】** 现有 07/10 demo 使用 `I2C_DEVICE_ADDR = 8'h60`（即 7-bit `0x30`，SID 默认低），与默认接法一致。

### I2C 时序参数

| Symbol | 参数 | Standard Min/Max | Fast Min/Max | 单位 |
|---|---|---|---|---|
| fSCL | SCL 时钟频率 | 0 / 100 | 0 / 400 | kHz |
| tHD;STA | (重复) START 保持 | 4.0 / – | 0.6 / – | μs |
| tLOW | SCL 低周期 | 4.7 / – | 1.3 / – | μs |
| tHIGH | SCL 高周期 | 4.0 / – | 0.6 / – | μs |
| tSU;STA | 重复 START 建立 | 4.7 / – | 0.6 / – | μs |
| tHD;DAT | 数据保持 | 0 / – | 0 / – | μs |
| tSU;DAT | 数据建立 | 250 / – | 100 / – | ns |
| tr | SDA/SCL 上升 | – / 1000 | – / 300 | ns |
| tf | SDA/SCL 下降 | – / 300 | – / 300 | ns |
| tSU;STO | STOP 建立 | 4.0 / – | 0.6 / – | μs |
| tBUF | STOP→START 空闲 | 4.7 / – | 1.3 / – | μs |
| tVD;DAT | 数据有效 | – / 3.45 | – / 0.9 | μs |
| tVD;ACK | ACK 有效 | – / 3.45 | – / 0.9 | μs |
| tSP | 输入滤波尖峰脉宽 | – / – | 0 / 50 | ns |

> 判断上升沿起始/下降沿终止阈值为 **30%**；判断上升沿终止/下降沿起始阈值为 **70%**。

## 6. MIPI 数据接口

> 来源：**【PDF2】** 1.6。

- SC431HAI 提供串行视频端口 MIPI，支持 **8/10-bit、1/2/4-lane**，推荐传输速率 **不大于 1.4 Gbps**。
- MIPI 信号：时钟差分 `MCP/MCN`，数据差分 `MD0P/N`、`MD1P/N`、`MD2P/N`、`MD3P/N`。
- **默认 VC（Virtual Channel）= 0**。

### 6.1 数据标识 DI

DI 由 VC 与 DT 组成：

```
DI<7> DI<6> DI<5> DI<4> | DI<3> DI<2> DI<1> DI<0>
        VC (2bit)      |         DT (6bit)
```

| DT | 描述 |
|---|---|
| `6'h00` | 帧起始短包 |
| `6'h01` | 帧结束短包 |
| `6'h02` | 行起始短包 |
| `6'h03` | 行结束短包 |
| `6'h2a` | 8-bit 模式下数据长包 |
| `6'h2b` | 10-bit 模式下数据长包 |

### 6.2 Multi-lane 字节分配

- 1-Lane：Lane1 依次 Byte0,1,2,…,N-1
- 2-Lane：Lane1 = Byte 0,2,4…；Lane2 = Byte 1,3,5…
- 4-Lane：Lane1 = 0,4,8…；Lane2 = 1,5,9…；Lane3 = 2,6,10…；Lane4 = 3,7,11…

### 6.3 MIPI 调整寄存器

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| MIPI lane 数量 | `0x3018` | `0x7a` | Bit[7:5]：`0`=1 lane，`1`=2 lane，`3`=4 lane |
| MIPI 输出数据模式 | `0x3031` | `0x0a` | Bit[3:0]：`8`=raw8，`a`=raw10 |
| PHY 数据模式 | `0x3037` | `0x20` | Bit[6:5]：`0`=8bit，`1`=10bit |
| MIPI clock 设置 | `0x303f` | `0x01` | Bit[7]：`0`=sel MIPI_pclk，`1`=sel DVP_pclk |
| MIPI LP 驱动 | `0x3650` | `0x31` | Bit[1:0] LP 驱动能力，默认 `2'h1` |
| MIPI HS 驱动 | `0x3651` | `0x9d` | Bit[3:0] HS 驱动能力，默认 `4'hd` |
| MIPI Lane0 延时 | `0x3652` | `0x00` | Bit[3] lane0 相位反向；Bit[1:0] 延时，**40ps/step** |
| MIPI Lane1 延时 | `0x3652` | `0x00` | Bit[7] lane1 相位反向；Bit[5:4] 延时 |
| MIPI Lane2 延时 | `0x3653` | `0x00` | Bit[3] lane2 相位反向；Bit[1:0] 延时 |
| MIPI Lane3 延时 | `0x3653` | `0x00` | Bit[7] lane3 相位反向；Bit[5:4] 延时 |
| MIPI Clock 延时 | `0x3654` | `0x30` | Bit[3] 时钟反向；Bit[1:0] 时钟延时，40ps/step |

> **调试提示**：PCB 走线不等长或眼图不佳时，可用 `0x3652/53/54` 的 40ps/step 延时与相位反转逐 lane 校正；配合 FPGA 侧 CSI RX 的 lane 交换/延时。

## 7. 锁相环 PLL

> 来源：**【PDF2】** 1.7。

- 输入时钟频率范围：**6 ~ 40 MHz**
- VCO 输出频率 FVCO 范围：**400 ~ 1400 MHz**
- 结构：`EXTCLK → Pre_Divider → PFD → LPF → VCO → Divider → FSYSCLK`

> **集成提示**：主板提供 25MHz/27MHz/50MHz 晶振。SC431HAI 的 EXTCLK 必须在 6~40MHz 内（**【PDF1】** 板级相机座未直接提供专用 sensor 时钟，实际由 FPGA/外部提供，见第三部分）。

## 8. 功能寄存器

> 来源：**【PDF2】** 2.1 ~ 2.6。

### 8.1 LED Strobe

- 模式 1：`0x3362[0]` 使能；输出引脚由 `0x300a[1]/[2]`、`0x3033[4]` 选择；脉冲开始位置 `{0x3382,0x3383}`，结束位置 `{0x3386,0x3387}`（结束需小于开始）。
- 模式 2：`0x4d0b[0]` 使能；脉冲宽度由 `{0x4d0c,0x4d0d}` 控制，单位 `{0x320c,0x320d}/2`；开始位置为第一个量化行开始曝光处。
- 由 `FSYNC` 引脚输出。

### 8.2 Slave Mode（外部同步曝光）

- `0x3222[0]=1` 使能 Slave Mode（0=Master）。
- 触发 pad 选择：`0x3224[4]`（1=FSYNC，0=EFSYNC）。
- `0x300a[2]`：FSYNC 输出使能；`0x300a[6]`：EFSYNC 输入使能。
- 帧长 VTS `{0x320e,0x320f}` 默认 `0x05dc`（最大 `0x7ff0`）；`RB rows` `{0x3230,0x3231}`；`Active Rows + Blank Rows = VTS − RB Rows`。
- EFSYNC/FSYNC 上升沿触发有效，高电平持续 ≥4 个 EXTCLK；上升沿间隔允许 **40ns** 偏差；建议 Active State 控制在 40ns 以内以保证帧内各行曝光一致。

### 8.3 行交叠 HDR

- `0x3281[0]=1` 使能 HDR。
- 通过 MIPI virtual channel 区分长短曝光：默认长曝光 VC=`2'b00`，短曝光 VC=`2'b01`。
- VC 控制：`0x4816[4]` hdr_vc_en，`[3:2]` Long Exposure VC，`[1:0]` Short Exposure VC。
- SE 起始点：`{0x3e23,0x3e24}` 默认 `0x0020`。
- 不使用 VC 时按行偏差区分（模式 a 只输出有效行；模式 b 插入 dummy 行）。
- `max long exposure = 2*{0x320e,0x320f} − 2*{0x3e23,0x3e24} − 21`。

### 8.4 AEC / AGC

- SC431HAI 本身无 AEC/AGC，需后端平台实现；策略为**曝光优先，曝光到头再调增益**。
- 曝光调节步长为**半行时间**；第 N 帧写入，**第 N+2 帧生效**；线性模式建议帧开始后写入。
- 手动曝光寄存器：

| 功能 | 寄存器 | 步长 | 最小值 | 最大值 |
|---|---|---|---|---|
| 长曝光（线性/长曝） | `{0x3e00[3:0],0x3e01,0x3e02[7:4]}` | 1（半行） | 4 | `2*VTS − 11` |
| 长曝光（HDR 长曝） | 同上 | 4 | 8 | `2*VTS − 2*SE − 21` |
| 短曝光（HDR） | `{0x3e22[3:0],0x3e04,0x3e05[7:4]}` | 4 | 8 | `2*SE − 19` |

- 增益寄存器：

| 模式 | ANA GAIN | ANA FINE GAIN | DIG GAIN | DIG FINE GAIN |
|---|---|---|---|---|
| 线性 / HDR 长曝 | `0x3e08` | `0x3e09` | `0x3e06` | `0x3e07` |
| HDR 短曝 | `0x3e12` | `0x3e13` | `0x3e10` | `0x3e11` |

> `0x3e08[7]` 是 DCG 增益开关。模拟增益范围 1.000~48.510（约 0~33.7dB），数字增益 1.000~15.750（约 0~23.9dB，精度 1/32）。一般先调模拟增益，再调数字增益。

### 8.5 Group Hold

- `0x3812` 写 `0x00` 开始打包，写 `0x30` 释放；最多打包 10 个寄存器。
- 帧延迟由 `0x3802[1:0]` 控制（0=当前帧，N=N 帧延迟）。

### 8.6 DPC（坏点消除）

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| 亮坏点消除 | `0x5000[2]` | `1` | 1=enable |
| 暗坏点消除 | `0x5000[1]` | `1` | 1=enable |

## 9. 视频输出模式

> 来源：**【PDF2】** 2.7 / 2.8。

### 9.1 读取顺序与颜色

- Active Array 2560H × 1440V，四周各有 4 行/列的 Active Border；First Pixel (0,0) 位于左上（A1 在左上时，top view）。
- 像素尺寸 2.0μm × 2.0μm。

### 9.2 镜像与倒置

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| 镜像 | `0x3221` | `0x00` | Bit[2:1]：`2'b00` off，`2'b11` on |
| 倒置 | `0x3221` | `0x00` | Bit[6:5]：`2'b00` off，`2'b11` on |

### 9.3 输出窗口寄存器

| 功能 | 寄存器 | 默认值 | 描述 |
|---|---|---|---|
| 窗口宽度 | `{0x3208,0x3209}` | `0x0a00` | 输出窗口宽度（默认 2560） |
| 窗口高度 | `{0x320a,0x320b}` | `0x05a0` | 输出窗口高度（默认 1440） |
| 列起始 | `{0x3210,0x3211}` | `0x0004` | 输出窗口列起始 |
| 行起始 | `{0x3212,0x3213}` | `0x0004` | 输出窗口行起始 |

> **【工程】** 07/10 demo 将窗口配置为 **1920×1080**：`0x3208/09 = 0x0780`、`0x320a/0b = 0x0438`；起始 `0x3210/11 = 0x0144`、`0x3212/13 = 0x0005`。详见第三部分。

### 9.4 帧率与帧长

- 一行时间 = `1 / (帧率 × 帧长)`。
- 帧长 `{0x320e[6:0],0x320f}` 默认 `0x05dc`。

# 第二部分 Ti60F225 主板相机相关硬件

## 1. FPGA Bank 与电压选择

> 来源：**【PDF1】** 2.3 / 2.4。

| Bank | 用途 | 电压 | FPGA 侧 |
|---|---|---|---|
| 3B、4A、4B | DDR3 | 固定 1.5V | bottom |
| 3A | HDMI | 固定 1.8V | right |
| 1A、1B | GE | 固定 1.8V | left |
| **2A、2B、TR、TL** | **QSE 扩展座 J7（MIPI/LVDS）** | **2A/2B 可选 1.2V / 1.8V** | top |
| BL、BR、TR、TL | LED、按键、GE 复位 | 固定 3.3V | – |

**关键结论（相机相关）**：
- MIPI IO 在 **Bank 2A**，电压由 **J2** 选择：**MIPI 选 `VCC_1V2`（1.2V）**，LVDS 选 `VCC_1V8`。
- Bank 2A/2B 由 **J2、J3** 控制。
- **Interface Designer 中设置的电压必须与外部硬件一致**；BR/BL/TR/TL 硬件为 3.3V，误选 1.8V 会烧坏 VCCIO。
- **MIPI 的 Bank 电压必须是 1.2V**。

> **【PDF3】芯片级补充**：本板 Ti60F225（I3 速度等级，核压 0.95V，−40~100°C）的 I/O 资源为 **HSIO 140 / HVIO 23**（全芯片 142/27 为 F256 封装数字）。HSIO bank 支持 1.2/1.35/1.5/1.8V，HVIO bank 支持 1.8/2.5/3.0/3.3V；MIPI lane 仅支持 1.2V。I3 等级下 LVDS 半速率与 MIPI 最高 1.5Gbps。

## 5. SOFT MIPI 硬件设计原则

> 来源：**【PDF1】** 7.1。

1. **MIPI 的 bank 电压是 1.2V。**
2. 一定要参考 pin out 文件：MIPI RX 信号定义为 `RX_DATA_P/Nx_Iy`（x=组内数据线编号，y=组号）；每组时钟 `RX_CLK_Iy` 位置固定，但**数据可以交换**。
3. MIPI TX 没有太多要求，放在 MIPI bank 即可。
4. 使用 HSIO 为 GPIO/LVDS/MIPI 时，GPIO、LVDS 和 MIPI 之间要**隔出一对未分配 IO**，以减少开关噪声（未隔开软件会报错）。
5. MIPI 输出要接相应 bank 的 **REF_RES** 管脚。
6. MIPI IO 所在 bank 电压配置成 1.2V。

> **【PDF3】REF_RES 参考电阻连接要求**：REF_RES 经 **10kΩ（±1%）** 电阻接地。
> - `REF_RES_2A` 与 `REF_RES_4A` 引脚**必须**连接。
> - 某 bank 的引脚用作 **LVDS TX 或 MIPI TX lane** 时，需连接该 bank 的 `REF_RES`。
> - 使用片上振荡器时需连接 `REF_RES_3A`；烧写安全熔丝也需 `REF_RES_3A`。
> - 上述均不适用时，REF_RES 可悬空。

## 6. 其它相关外设要点

> 来源：**【PDF1】**。

仅列出与相机/视频系统集成相关的内容，完整说明见《用户手册》。

- **DDR3**：MT41J128M16JT-125，16 位，2Gb，最高 800Mbps（部分文档写 1600Mbps），Bank 3B/4A/4B，固定 1.5V。相机帧缓存常用。
- **HDMI**：FPGA 高速 IO + LVDS 模拟，接收端 50Ω 上拉 + 电容耦合，发送交流耦合；**差分对 P/N 对调**；勾选 `Enable Common Mode Driver`；Bank 3A 1.8V。
- **GE**：YT8531SC(SH)，RGMII，Bank 1A/1B 1.8V。
- **Flash**：GD25LQ64，8MB SPI NOR，CLK 脚不预留电容。
- **UART**：UART_RX=`GPIOL_02`(R4)，UART_TX=`GPIOR_28`(R14)，经 FT4232。
- **下载/供电**：板载 FT4232HL，一根 Type-C 完成供电+下载+UART；下载器 VCC 必须接。

## 3. I2C / 时钟 / 复位连接

- **I2C 地址**：SC431HAI 默认 SID 低 → 7-bit `0x30`，8-bit 写 `0x60`。**【工程】** 07/10 的 `i2c_master_ctrl_top` 参数：`I2C_DEVICE_ADDR = 8'h60`、`I2C_REG_ADDR_WIDTH = 16`、`CLK_DIV = 16'h0020`、`DATA_LENGTH = 161`。
- **上拉**：SDA/SCL 需 4.7kΩ 上拉（典型应用图为上拉到 DOVDD）。
- **复位**：`XSHUTDN` 由 FPGA `GPIOR_16` 控制（demo `o_cam_rst_p`），低有效；上电后需保证 T4≥4ms 再释放。
- **时钟**：`EXTCLK` 6~40MHz，占空比 45~55%；需在 DOVDD 上电且 XSHUTDN 释放前/后满足数据手册上电时序。
- **PLL**：输入 6~40MHz，VCO 400~1400MHz。

## 4. 寄存器初始化与窗口配置

> **【工程】** 07/10 demo 通过 `i2c_master_reg_rom.v`（161 项）初始化 SC431HAI，并配置为 1920×1080 RAW10 输出。

**关键寄存器摘录**（来自工程 ROM 与数据手册对应）：

## 5. Bring-up 检查清单

按顺序执行，每步通过后再进行下一步：

1. **供电核对**：子卡 AVDD=2.8V、DVDD=1.2V、DOVDD=1.8V 正常；FPGA Bank 2A/2B=1.2V（J2/J3）。
2. **上电时序**：DOVDD→DVDD→AVDD→XSHUTDN，`T4≥4ms`；下电时 DOVDD 掉电后不得有高电平信号。
3. **I2C 通信**：读 `0x3107/0x3108`，期望 `0xCD6B`；确认地址 `0x60`（SID 低）。
4. **复位/时钟**：确认 `EXTCLK` 频率 6~40MHz、占空比 45~55%；`XSHUTDN` 已释放。
5. **写入初始化序列**：按工程 161 项 ROM 配置；确认窗口 `0x3208/09=0x0780`、`0x320a/0b=0x0438`、lane/bit 模式正确。
6. **开启测试图**（可选）：`0x4501=0xac` 灰度递增模式，便于验证链路。
7. **MIPI 链路**：CSI RX 侧确认 `cam_ck` 时钟、lane 映射、数据对齐；必要时用 FPGA IP 的 lane swap / delay 与 sensor 的 `0x3652/53/54`（40ps/step）校正。
8. **图像校验**：关闭测试图，确认无花屏/错行、颜色正确（RAW/Bayer 相位）、帧率稳定。
9. **状态指示**：0.5~1s 周期闪烁类 LED 指示；07/10 demo 中 `led[0]` 与 DDR3 `cal_done` 相关（相机+DDR3 路径）。
10. **长时间稳定性**：高温（≤+85°C 工作，最佳 −20~+60°C）与电压波动下复测。
