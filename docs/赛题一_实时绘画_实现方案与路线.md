# 赛题一「AI 赋能的实时绘画——风格化视频渲染系统」实现方案与路线

> 配套文档：《赛题一_实时绘画_任务分级与硬件实现分析.md》（任务分级/资源预算）、《SC431HAI_硬件设计指南.md》（传感器/板级集成）、《Ti60F225_DemoBoard_v4_用户手册.md》（板卡与 Demo 工程）。
> 本方案为**模块化实现路线**，原则：基础线 L0→L4 一条主线跑通，加分项 L5a~L5d 各自独立成模块、分开成路线。
>
> 关键决策：
> - **处理分辨率**：网络按 **640×480** 设计（采集 1920×1080 → Resize 到 640×480 进网络 → 显示放大回 720p/1080p）。
> - **风格迁移网络**：**Fast Neural Style 1/4 通道版**（INT8 量化 + BN 折叠进卷积）。
> - **复用工程**：`07`/`10`（采集+DDR）、`08`（Sapphire SoC）、`03`（HDMI TX）、`11`（CSI 自环）、`17`（UART）。

## 一、总体原则

1. **模块化、可插拔**：每个功能独立成模块，接口标准化（AXI4/AXI4-Stream 数据流 + AXI-Lite/APB 控制），基础线与加分项解耦。
2. **一条主线跑通（L0→L4），加分项各自独立（L5a~L5d）**：加分项互不依赖，按需挂载。
3. **复用官方 Demo** 做大件 IP 的"即插即用件"，自研只做差异化部分（预处理、CNN、OSD）。
4. **分辨率锁定 640×480**（采集可 1920×1080，Resize 到 640×480 再进网络，显示再放大回 1080p/720p）。

## 二、顶层模块划分（模块化骨架）

```
                    ┌──────────────────────── Ti60F225 ────────────────────────┐
 SC431HAI ──► M1 采集 ─► M2 预处理 ─► M3 存储(DDR3) ◄──┐
              (CSI+I2C)   (Debayer/Resize)   三缓冲      │
                                                         │
        M6 控制(RISC-V Sapphire) ──► M4 加速器(CNN) ─────┘
              │                        │
              └────► M5 显示(OSD/HDMI) ◄┘
                      │
     M7+ 加分模块(可选): 多风格切换 / 高清 / 自研网络 / 交互
```

| 模块 | 职责 | 关键子模块 | 复用工程 | 资源(估) |
|---|---|---|---|---|
| **M1 采集** | MIPI RX + CSI-2 解析 + I2C 初始化 | `efx_csi2_rx`、`i2c_master_ctrl_top`、`sensor_clipper` | 07/10/11 | 大(IP 内) |
| **M2 预处理** | RAW10→RGB(Debayer) + Resize 640×480 | `debayer_top`、`resize`(最近邻→双线性) | 07/10 | ~3–5K LE |
| **M3 存储** | DDR3 帧缓存 + AXI 互连 | `ddr3_top`(16bit/AXI128)、`frame_buffer`(三缓冲) | 07/08/09 | ~3–6K LE |
| **M4 加速器** | FNS 1/4 通道 CNN 推理 | 卷积阵列/ReLU/BN折叠/IN近似/上下采样 | 自研 | DSP 主力 |
| **M5 显示** | OSD 分屏 + FPS + HDMI TX | `dvi_encoder`、`data_tx`、`color_bar_rgb` | 03/09/10 | ~3–6K LE |
| **M6 控制** | RISC-V 调度 + 外设 | `efx_soc`(Sapphire)、UART/GPIO/I2C | 08 | ~8–15K LE |
| **M7a~d 加分** | 见第五节，独立挂载 | 各自小模块 | 见下 | 各 ≈0–少量 |

**接口约定**（模块化关键）：

- 图像数据一律走 **AXI4 / AXI4-Stream + DDR 帧缓存**；
- 控制/寄存器一律走 **AXI-Lite / APB**；
- 每个模块保留「使能 / 完成 / 中断」三线握手。

## 三、基础线路线（L0→L4，必做主线）

### L0 环境与板级打通

1. 建 Efinity 工程（Titanium / Ti60F225 / **I3**，必须指定 Top Module）。
2. 复刻 01 点灯 + 03 HDMI 彩条 + 17 UART 回环。
3. **验收**：HDMI 彩条稳定、串口可交互、LED 闪烁。
4. **硬件核对（定基线）**：`J2/J3=1.2V`、HDMI Bank 3A=1.8V、Interface Designer 电压与硬件一致。

### L1 采集 + 预处理 + DDR 三缓冲

1. 复用 10 采集通路：`efx_csi2_rx` 4-lane + SC431HAI 161 项 I2C（`0x60`、1920×1080 RAW10）。
2. `sensor_clipper` → `debayer_top`(RAW10→RGB888) → `resize`(最近邻到 640×480)。
3. 写 `frame_buffer` 三缓冲到 DDR3。
4. **验证顺序**：先开测试图 `0x4501=0xac`（灰度渐变）确认 MIPI 链路与对齐；再关测试图确认无色偏/错行/丢帧。
5. **验收**：640×480 稳定写入 DDR；LED0=DDR `cal_done`、LED1=视频稳定。

### L2 加速器单模块（卷积/ReLU/BN）

1. **离线模型侧**（PC/Python）：取 FNS 权重 → 剪成 1/4 通道 → INT8 量化 → **BN 折叠进卷积** → 导出量化权重（.hex，供 DDR/Flash 加载）。
2. 硬件做最小可验证单元：3×3 卷积（8~16 个 MAC）+ ReLU + AXI4 读写 DDR。
3. **验收**：固定测试图/固定权重，硬件结果与 Python 参考逐位比对（或误差 <1LSB）。

### L3 完整网络 + RISC-V 协同 + 上屏

1. 组装完整 FNS 1/4 通道（下采样×N → 卷积堆 → 上采样×N）；**Instance Norm 用 BN 替代或硬件近似（逐通道移动均值/LUT）**。
2. 挂 Sapphire SoC（08）：C 驱动做 `sensor 初始化 → 权重加载到 DDR → 配置加速器寄存器 → 启动 → 中断/轮询等待 → 切帧`。
3. 结果帧经 M5 输出 HDMI。
4. **验收**：屏幕可见风格化视频，RISC-V 可启停加速器。

### L4 基础 Demo 达标（对比视图 + FPS）

1. OSD 模块：左原图 / 右风格图分屏（显示控制器按坐标选 DDR 地址），或按键切全屏。
2. 字模 ROM 叠加 FPS（帧计数 + 秒基准）。
3. **验收**：640×480 稳定 **≥15fps**（官方硬指标）。
4. **性能预算核对**：FNS 1/4 通道在 640×480 约 0.5–1.5 GMAC/帧 ×15fps ≈ 7.5–22.5 GMAC/s，落在 160 DSP 有效能力内，可行。

## 四、硬件资源配置（能直接配 vs 手动）

### 4.1 物理层配置（需手动，本方案只给清单）

| 项目 | 要求 | 位置 |
|---|---|---|
| 跳线 J2/J3 | **1.2V**（MIPI Bank 2A/2B） | 板卡 |
| 摄像头接线 | 接 J4（或 CSI2QSE 子卡转 J7） | FPC |
| MIPI 映射 | MCP→`GPIOT_PN_09`、MD0→`PN_07`、MD1→`PN_10`、MD2→`PN_06`、MD3→`PN_11` | J4 |
| I2C/复位 | SCL→`GPIOR_20`、SDA→`GPIOR_18`、RST(XSHUTDN)→`GPIOR_16` | J4 |
| 电平转换 | J4 的 SCL/SDA/RST=3.3V vs SC431HAI DOVDD=1.8V，**需确认子卡已做 1.8V 转换** | 子卡 |
| 供电 | AVDD=2.8V / DVDD=1.2V / DOVDD=1.8V，上电顺序 DOVDD→DVDD→AVDD→XSHUTDN(T4≥4ms) | 子卡 |
| HDMI | HDMI TX（Bank 3A，1.8V）接显示器 | 板卡 |
| USB | 一根 Type-C 完成供电+下载+UART（FT4232） | 板卡 |

### 4.2 工程层配置（执行阶段可直接写文件）

- **Interface Designer 电压**：MIPI=1.2V、HDMI=1.8V、GE=1.8V、DDR3=1.5V、按键/LED=3.3V（必须与硬件一致）。
- **CSI-2 RX IP**（`efx_csi2_rx` 5.15）：4-lane、Continuous clock、`HS_BYTECLK_MHZ≈70~175`、`PIXEL_FIFO_DEPTH 2048~4096`。
- **SC431HAI I2C 初始化**（复用 07/10 `i2c_master_reg_rom.v` 161 项）：`I2C_DEVICE_ADDR=8'h60`、16-bit 地址、1920×1080 RAW10（`0x3208/09=0x0780`、`0x320a/0b=0x0438`、`0x3018`=4-lane、`0x3031=0x0a`=raw10）。
- **PLL**：像素时钟 25.175/74.25MHz、MIPI byte/pclk、DDR3 参考、系统时钟。
- **DDR3**：软核控制器，16-bit、AXI 128bit、三缓冲 `FB_NUM=3`。
- **HDMI TX**（复用 03 `dvi_encoder`）：勾选 `Enable Common Mode Driver`、差分对 P/N 对调。

## 五、加分项方案（分开做，各自模块化路线）

> 各加分项互不依赖，按需挂载，均以 L4 为基础。

### L5a 多风格实时切换（性价比最高，资源增量≈0）

- 路线：DDR/Flash 预置 ≥2 组权重 → 切换=更新加速器「权重基址」寄存器 + 帧边界冲刷 → 权重双缓冲预取防半帧混用。
- 触发：按键（复用 01 消抖）/ 串口指令（17）。
- 验收：切换 <100ms、不丢帧、不重配 FPGA。

### L5b 分辨率/帧率提升（最体现 FPGA 功力）

- 路线：640×480 基础上 → 行流水线(Line-based) + 层间融合 + 权重固定流/脉动阵列 → 目标 720p@30。
- 关键：减少 DDR 中间特征图往返；必要时 INT8→更低精度/稀疏。
- 验收：1280×720@30 稳定，DDR 读写次数明显下降。

### L5c 超轻量网络自设计（<500KB）

- 路线：结构化剪枝 + 通道裁剪 + 权值共享/稀疏；可评估 BNN/TNN(XNOR+popcount)。
- 交付：结构图 + 参数量表 + 与标准网络 PSNR/SSIM/延迟对比。

### L5d 创意交互（现场演示性）

- 语音：SPI 语音模块 → RISC-V 发切换指令（复用 M6 串口通路）。
- 手势：复用摄像头帧差/连通域，FPGA 加速 → 触发滤镜切换。
- 推流：WiFi(UART/SPI) 或 GE(04) 压缩帧推手机 APP。
